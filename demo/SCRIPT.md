# Demo video: "Ask Higgsy" (1:53, limit is 2:00)

The finished video is built by scripts from the live site, so it can be redone when the app changes:
`demo/out/final/ask-higgsy-demo.mp4` (1920x1080, about 11 MB). It is not committed; build it with the commands at the bottom.

| Time | What's on screen | How it was made |
| --- | --- | --- |
| 0:00 - 0:10 | Higgsy waves, title card | `01-intro`: the LTX-2.3 greeting clip plus a title card, narrated |
| 0:10 - 0:19 | "It never makes up a price" | `02-never-invents`, narrated |
| 0:19 - 1:22 | **A real call on https://hana-comfy-hack.vercel.app** | `05-live-call`: recorded by `demo/record-call.js` and cut at sentence ends |
| 1:22 - 1:43 | "Everything you see was made with ComfyUI" | `03-built-with-comfyui`, narrated, four rows appear one by one |
| 1:43 - 1:53 | Links and hashtag | `04-end-card`, narrated |

Two things to know about the sound:
- **The narration** is an Indian English male voice from ElevenLabs (Viraj, "Confident and Natural"), generated by `demo/make-voiceover.py`.
- **The caller** in the live call is also a synthesized voice (the same one), played into a virtual microphone so the call can be reproduced exactly. A line on screen says so ("Live call · the caller's voice is synthesized"). Higgsy's own voice is the agent's real output from the live site.

The call itself is real: the deployed app, the real voice agent, the real lookup in Higgsfield's pages, and a real image generated on Comfy Cloud. Only the cuts are edited: pauses are trimmed and long answers stop at a sentence end.
The four questions: "What does the Plus plan cost?", "How do I cancel my subscription?", "How much is the Mega Ultra plan?" (there is no such plan, so she refuses), and "Can you show me an example? A small red paper boat on calm water."

## Rebuild it
```bash
set -a; . ./.env.local; set +a                    # ELEVENLABS_API_KEY (a paid plan, for library voices)
python3 demo/make-voiceover.py                    # the seven narration lines
python3 demo/build-cards.py && bash demo/build-final.sh   # the four narrated clips
NODE_PATH=$(npm root -g) node demo/record-call.js # records a call (headless Chromium, virtual microphone)
python3 demo/analyze-call.py                      # finds the sync flash and Higgsy's sentence boundaries
# choose the cut points (sentence ends) in demo/edit-call.py, then:
python3 demo/edit-call.py                         # cuts the call and joins everything
```
`demo/record-call.js` retries a question once if the agent says it didn't hear it.
